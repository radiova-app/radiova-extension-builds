# Radiova v1.1.0
Дата випуску: 2026-11-25

## Додано
- Станції тепер надходять зі спільного каталогу Radiova (близько 300 станцій). Каталог перевіряється контрольною сумою SHA-256, кешується для роботи без мережі, а вбудований список станцій лишається останнім резервом.
- Збірка для Firefox. Там відтворення працює у фоновій сторінці розширення.

## Змінено
- Улюблені, приховані станції, списки, остання станція та статистика автоматично переносяться на нові ключі каталогу. Станції, яких немає в каталозі, лишаються доступними, як і раніше, а попередні значення спершу зберігаються в резервній копії.
- Старе онлайн-джерело станцій більше не використовується.

## Виправлено
- Вікна додавання джерела Discover і редагування списку винятків у панелі керування.

## Відомі проблеми
- Вхід через Google не входить до цього випуску.
- Збірку для Firefox перевіряли лише автоматичними тестами, не в справжньому Firefox.

## Підтримувані браузери
- Chrome
- Firefox
- Edge
- Brave
- Opera
- Vivaldi
