# Contributing

This repository contains **pre-built releases** of the Radiova browser extension.

If you want to report a bug or suggest a feature, please open an issue in the [issue tracker](https://github.com/radiova-app/radiova-extension-builds/issues).

For security vulnerabilities, please refer to [SECURITY.md](SECURITY.md).

This repository does **not** accept pull requests with source code changes, as the source code is maintained in a private repository.
