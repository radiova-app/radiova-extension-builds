# Security Policy

## Supported Versions

Only the latest stable release receives security updates.

| Version | Supported          |
|---------|--------------------|
| latest  | Yes                |
| < latest| No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Radiova, please **do not** report it publicly via GitHub issues.

Instead, send a description of the issue to:

**security@radiova.app** *(placeholder — to be confirmed)*

Please include:

- A brief description of the vulnerability
- Steps to reproduce it
- Affected browser and version
- Your contact information (optional)

You should receive a response within 5 business days. If the vulnerability is confirmed, a fix will be prepared and released as soon as possible.

## Disclosure Policy

- We will acknowledge receipt of your report within 5 business days.
- We will keep you informed of the progress toward a fix.
- Once a fix is released, we may publicly disclose the vulnerability after a reasonable period to allow users to update.

## Scope

This security policy applies to the built extension packages in this repository. For vulnerabilities in the source code, please refer to the main development repository.
